# 🐘 Aula 6 - PHP CRUD

## 📚 Sobre a aula

Projeto desenvolvido durante a **Aula 6**, utilizando PHP para implementar operações de **CRUD**.

CRUD significa:

- 🟢 **C**reate - Criar
- 🔵 **R**ead - Consultar
- 🟡 **U**pdate - Atualizar
- 🔴 **D**elete - Excluir
